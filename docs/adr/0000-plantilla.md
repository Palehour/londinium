# ADR NNNN: <título corto>

- **Estado:** Propuesto | Aceptado | Reemplazado por ADR NNNN
- **Fecha:** AAAA-MM-DD
- **Origen:** issue o PR donde se decidió

## Contexto
Qué problema o restricción obliga a decidir. Lo mínimo para entender el resto.

## Decisión
Qué se decidió, en presente y sin ambigüedad.

## Estado
Propuesto mientras el PR está abierto; con la aprobación de Cristian, el autor lo cambia a Aceptado en un commit del
mismo PR, antes del merge. Un ADR que revierte o cambia otro sobre la
misma decisión lo reemplaza, y el viejo no se borra: se marca "Reemplazado por ADR NNNN". Los ADR de otros temas
no se tocan.

## Consecuencias
Qué se vuelve más fácil, qué se vuelve más difícil y qué reglas siguen de acá (tests, código, datos).
